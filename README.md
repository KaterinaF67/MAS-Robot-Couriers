# Многоагентная система роботов-курьеров

Лабораторная работа № 2 по многоагентным системам.

Проект представляет собой симуляцию склада, где роботы-курьеры получают заказы и перевозят грузы между точками. Роботы перемещаются по клеточной карте с препятствиями, строят маршруты, расходуют заряд аккумулятора и взаимодействуют с диспетчером и зарядными станциями через сообщения.

## Распределение заказов

Реализованы два механизма:

- **Централизованная диспетчеризация:** диспетчер оценивает доступных роботов и назначает заказ подходящему исполнителю.
- **Contract Net:** диспетчер объявляет заказ, роботы отправляют предложения, после чего выбирается исполнитель.

Оба механизма проверяются на одинаковых начальных условиях. Программа собирает показатели выполнения заказов, времени назначения и доставки, количества сообщений и затрат на координацию.

## Структура проекта

- `mas/core.py` — модель склада, агенты, маршрутизация, сообщения и алгоритмы распределения заказов.
- `mas/__init__.py` — импорт основных классов.
- `run.py` — запуск симуляции с выбранными параметрами.
- `experiments.py` — серия сравнительных экспериментов.
- `plots.py` — построение графиков по результатам экспериментов.
- `tests/` — автоматические тесты.
- `results/` — результаты запусков (`runs.csv`, `summary.csv`, `config.json`) и графики (`*.png`).
- `requirements.txt` — зависимости для построения графиков.

## Запуск

Требуется **Python 3.10+**. Команды выполняются из корневой папки проекта, в которой находится `run.py`.

**Запуск обоих алгоритмов:**

```powershell
py run.py --mode both
```

Отдельный режим:

```powershell
py run.py --mode central
py run.py --mode contract
```

Пример с изменением числа роботов и заказов:

```powershell
py run.py --mode both --robots 6 --orders 20 --seed 42
```

Список доступных параметров:

```powershell
py run.py --help
```

**Автоматические тесты:**

```powershell
py -m unittest discover -s tests -v
```

**Повторение экспериментов и построение графиков:**

```powershell
py experiments.py
py -m pip install -r requirements.txt
py plots.py
```

Результаты сохраняются в папку `results/`. Для основной симуляции сторонние библиотеки не требуются; `matplotlib` используется при построении графиков.
